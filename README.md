# Copilot Agents Follow-Along (MS-4019)

A hands-on GitHub Pages site for **MS-4019: Transform your everyday business processes with agents**, with two sections:

1. **Explore prebuilt Microsoft 365 Copilot agents**: Researcher, Analyst, Prompt Coach, Idea Coach and Writing Coach
2. **Build and manage an agent**: a trainer demo, four build options (Product Knowledge Helper, Meeting Prep Assistant, New-Hire Onboarding Buddy, and the MS-4021 Immersion Experience – Agents (Executives) exercise), plus test, SharePoint agent and sharing

All data is fictional (**MapleWheel Retail Group**). There are no meeting or email samples.

## Publish on GitHub Pages
1. Create a new public repository and upload everything in this folder, keeping the `data/` folder structure.
2. Go to **Settings → Pages → Build and deployment**, set **Source** to *Deploy from a branch*, and choose *main* / *(root)*.
3. Your site will be at `https://<your-account>.github.io/<repository-name>/`.

## Files
- `index.html`: the follow-along page (copy buttons for every prompt)
- `data/section1-prebuilt-agents/`: Analyst and Writing Coach practice files
- `data/section2-build-an-agent/`: knowledge files for the trainer demo, options A to C, and the SharePoint agent
